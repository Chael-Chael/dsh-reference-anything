# 0.5.0 更新清单（待用户审稿）

比较基线：远端最新正式 Release / npm latest 0.4.4，Git tag `v0.4.4`（`6cb4366`）。本清单覆盖该标签之后的提交与当前工作区实现，不把已有的本地插件来源、自定义快捷词、网盘引用等再次当成全新功能。不是已发布声明，也不表示全部发版验收通过。

## 新增功能

1. 本地 Agent 会话可通过 Tab 打开操作菜单，确认后导入完整历史，或生成交接摘要；引用与导入分别处理，提供相关动作设置。
2. 本地扫描和只读引用独立于 Chat Import：内置上游扫描/解析快照，扫描目录覆盖 29 种来源；Chat Import 仅负责导入、摘要和导入状态。目录覆盖不等于 29 种来源均已实机验收。
3. 本地引用采用可读的 source/path/sessionId 定位信息，发送时自动提供有预算的正文预览；支持重启后继续读取，以及完整定位块跨会话复制。
4. 按需读取正文或工具记录，按消息编号定位；新增正文搜索 `reference_search` 与原生图片读取 `reference_image`，通过 revision 检测来源变更。
5. 每次发送重新计算多条本地引用共享的剩余上下文预算，计入历史、当前消息、系统提示、工具和输出预留；容量未知时延后正文解析，保留定位说明。不会截短用户当前问题。
6. 设置页支持当前版本发布说明及功能卡/GIF 展示；更新检查同时保留当前版与新版说明。

## 体验优化

7. 后台检查本地会话正文可用性，隐藏已确认空记录；异常、未知结构或超过后台预算的记录保留，文件变化后重新检查。菜单、模型列表和设置计数使用一致逻辑。
8. 本地扫描使用子进程和短期缓存，隔离失败、保留来源警告，避免在输入路径重复扫描和全文解析。
9. 本地 Agent 图标与来源识别扩展；筛选按来源 kind 工作，保留扫描警告。
10. Chat Import 不兼容、不可用、被禁用或查询失败时提供具体状态；可升级时展示升级入口，正常状态不显示异常提醒。
11. 网页会话菜单显示连接就绪状态，启动时执行轻量健康检查；设置页区分 Browser Bridge、Profile 和扩展版本问题。
12. OpenCLI 固定为随插件安装的 2.0.0 依赖，适配管理命令的 JSON 输出；仍支持显式指定外部可执行文件。网页适配器独立版本为 0.2.3，不跟随主包改成 0.5.0。
13. 改进菜单首次打开的高亮、异步候选稳定性、动作选中行为、文件夹下钻和多引用快捷词处理。

## 问题修复与兼容性

14. 修复 Codex 附件包装导致用户正文丢失，保留图片消息与 Codex/Claude 压缩检查点。
15. 修复 Antigravity 类型化工具结果及异步 sidecar 关联，避免真实输出被缺失占位或无关结果替代；其他解析器修正及来源样例详见 local-reference-preview.md。
16. 本地工具结果采用有界的宿主原生输出契约，避免二次截断导致 JSON 不完整；保留宿主策略拒绝和替换结果。
17. 增强来源根目录、真实路径、会话身份与授权校验；引用正文内的引用文本不能自动获得新的读取权限。SQLite 只读，图片大小和工具输出有上限。
18. **不迁移旧格式本地引用**：旧的本地 dsh-ref/ref/cursor 引用需要重新从菜单选择；路径依赖当前机器，原文件删除后无法回读。
19. 大记录完整解析仍可能占用与源文件大小相关的内存；共享预算是保守估计，必要定位元数据不构成绝对不超上下文窗口的保证。
