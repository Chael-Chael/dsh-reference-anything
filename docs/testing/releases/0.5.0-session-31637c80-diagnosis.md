## 工具说明与实现的可改进点

- seq 7 同时声明 localText?: string 和 messages 数组，但没有说明本地来源正文只在 localText。src/tool.ts 的本地分支实际返回 messages:[]，而 render 将 localText 直接呈现；直接工具调用与 PTC 编程消费的体验不同。模型合理地读取 messages 会得到空结果，因此这部分不能全部归咎于模型。
- 总说明说本地不接受 detail，字段说明却说 external Agent sessions 可用 detail，术语接近，容易混淆。应明确区分 local Agent 与非本地来源。
- 优先提供可直接消费的本地结构化 messages/分页元数据，避免模型自行从带 XML 标签的文本中截取 JSON；若暂不改接口，至少在返回字段说明及示例中明确 localText 的格式和 messages 为空的条件。
- 50 条上限已有说明，改成更显眼的本地分页例子可降低误用，但 limit=60 和未定义 r0 仍是模型错误。
