## 失败调查与保留边界

### F-052-01：真实语料预算仍失败

原始测试枚举所有文件，错误地把最大 `.jsonl.zst` 直接交给仅匹配 `.jsonl` 的原生Codex适配器，导致超时及空对话错误。现在按真实适配器matches选样，没有修改压缩支持范围。修正后仍暴露文本超限，不能算修好整个测试。

源码核对：原生read接口按回合数、maxScanBytes和maxLineBytes约束；并不承诺2M总字符限制。模型工具另有输出预算。不能用这次底层返回直接断言模型收到了4M字符，也不能为了变绿放宽断言或截断正文破坏分页。后续须将真实大文件的模型输出预算与底层扫描预算分别验证，并解决原断言的契约问题。当前仍FAIL，不放行。

### CI根因

Linux附件测试暴露真实清理缺陷：dev/ino在删除重建后可复用。增加创建时间核对；新确定性测试模拟相同inode、不同创建时间，在旧代码上因替换文件被删失败。birthtime精度依赖文件系统，非原子路径清理仍存在竞态边界；未扩大递归删除范围。

两项OpenList失败是测试只给Windows ACL seam计数/注入错误，POSIX实际使用chmod；修正测试使两平台各自检查权限操作，未放宽凭据权限。
