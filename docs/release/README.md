# 发布说明与功能素材

版本正文、功能卡和媒体统一放在这里。每个版本使用一个与 `package.json` 版本号完全一致的目录（不带 `v`）：

```text
docs/release/
  0.4.4/
    README.md
    features.json
    demos/
```

`README.md` 是双语发布正文，也是发布 CI 读取的唯一原文；`features.json` 是应用内功能卡，媒体路径相对于版本目录。现有版本：[0.4.4](0.4.4/README.md)、[0.5.0](0.5.0/README.md)。发布及审稿流程见[发布素材](../development/release-materials.md)。

`features.json` 是按展示顺序排列的卡片数组。每张卡片包含：

```json
[
  {
    "title": "新功能标题",
    "description": "介绍这个功能，以及用户如何使用它。",
    "media": "demo.gif",
    "alt": "动画中展示的操作"
  }
]
```

图片支持 PNG、JPEG、WebP 和 GIF；路径相对于该版本目录，不可指向目录外。介绍支持 Markdown 段落、列表和链接；链接在新窗口打开。标题和介绍必填；纯文字预告可以省略 media 和 alt，提供图片时必须填写 alt。将预告放在数组最后，即作为最后一页展示。

执行 `npm run build` 后，配置和素材会内嵌到插件客户端，离线也可查看；修改内容后需要重新构建并重载 DSH。请压缩大 GIF，避免增加客户端加载时间。新增版本只需新增目录和内容，不需要修改卡片组件。

卡片可增加 `en: { title, description, alt }` 保存英文原文，媒体共用。默认字段为中文；卡片跟随 DSH 语言设置即时切换，其他语言使用英文，旧版未配置英文的卡片保留原文。GIF 画面内的文字不会自动翻译。

点击菜单项打开介绍后，用右下角“上一个／下一个”切换；关闭弹窗不会隐藏菜单项，只有点击菜单行的叉号才会屏蔽该版本。没有本地卡片配置的版本回退到原来的更新日志。未安装的新版本若尚未包含在本地插件中，也使用远端日志。

每个已安装版本首次进入“引用万物（dsh-reference-anything）”插件的具体设置页面时，会自动展示一次本次更新介绍；仅打开设置窗口或其他设置页不会触发。展示记录单独保存在本地存储中，与菜单入口的叉号互不影响；检测到远端新版本不会触发，安装后版本变化才会再次展示。首次启用此机制时，当前版本也会展示一次。本地存储不可用时，只能保证本次运行内不重复展示。

0.4.4 的初始卡片复用了仓库已有的文件、命令菜单示意图，可直接替换为实际新功能截图或 GIF。
