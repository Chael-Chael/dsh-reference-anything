Reference Anything marks, copied from `images/` in the repository.

- `logo.png` is the full-color mark: a blue @ wrapped around the DeepSeek whale. Use it on README, banner and release cards. Do not use it inside the DSH UI.
- `logo-mono.png` is a single-ink black mark with a white background, shown at 16px in the DSH settings nav. Its background is removed by blending, and it is inverted with `filter: invert(1)` in dark mode.
- `logo-icon.png` is the square app icon.

Never redraw or recolor the mark. On a dark ground, use the mono mark inverted.
